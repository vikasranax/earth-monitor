# M28 — Elections & Political Calendar

## Honest scope
No live API exists for a global elections calendar. This is a manually curated
starter set — only elections with well-documented, constitutionally fixed
cycles are included, each with a `confidence` field (`fixed_cycle` vs
`expected_window`). Dates for countries without a fixed schedule (UK, most
parliamentary systems that can call snap elections) are deliberately omitted
rather than guessed.

## Expanding this
Cross-reference official electoral commission sources per country before
adding entries. Do not add a date without a verifiable, cited source.
